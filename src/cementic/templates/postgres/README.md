# cementic Postgres setup

This directory contains a local Postgres service for cementic with `pgvector`
and `pgvectorscale`. It is generated by `cementic init postgres DIR`.

## One-time start

Docker:

```bash
docker compose up -d
docker compose ps
docker compose logs postgres
```

Podman:

```bash
podman compose up -d
podman compose ps
podman compose logs postgres
```

You do not need to run Compose every time you use cementic. The Compose service
uses `restart: unless-stopped`, so it is intended to stay available as a local
persistent database service.

After it starts, check cementic readiness:

```bash
cementic status --doctor
```

Then use cementic normally:

```bash
cementic start ~/docs -c research
cementic search "your query" -c research
```

## Defaults

The `.env` file matches cementic's built-in database defaults:

```text
CEMENTIC_DB_USER=cementic
CEMENTIC_DB_PASSWORD=cementic
CEMENTIC_DB_NAME=cementic
CEMENTIC_DB_PORT=5432
```

If you change these values, set the matching `CEMENTIC_DB_*` environment
variables before running cementic, or put the equivalent values in your cementic
config file.

## Optional Podman Quadlet service

The `quadlet/cementic-postgres.container` file is an optional user-systemd setup
for Podman. Copy it to your user Quadlet directory, then reload and enable it:

```bash
mkdir -p ~/.config/containers/systemd
cp quadlet/cementic-postgres.container ~/.config/containers/systemd/
systemctl --user daemon-reload
systemctl --user enable --now cementic-postgres.service
systemctl --user status cementic-postgres.service
```

For services that should survive logout/reboot, also run:

```bash
loginctl enable-linger "$USER"
```

## Stop or remove

Stop the service but keep data/image:

```bash
docker compose stop
# or: podman compose stop
```

Remove the Compose container/network:

```bash
docker compose down
# or: podman compose down
```

## Troubleshooting

- Port conflict: edit `CEMENTIC_DB_PORT` in `.env`, restart Compose, and set the
  same `CEMENTIC_DB_PORT` for cementic.
- Database unreachable: run `docker compose ps` / `podman compose ps`, inspect
  `docker compose logs postgres` / `podman compose logs postgres`, then rerun
  `cementic status --doctor`.
- Extension unavailable: rebuild the image with `docker compose build --no-cache`
  or `podman compose build --no-cache`.
- Changed `.env`: recreate the container with `docker compose up -d --force-recreate`
  or `podman compose up -d --force-recreate`.
